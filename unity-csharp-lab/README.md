# Unity C# Lab

Mini-laboratoire pédagogique dans le navigateur pour apprendre les bases de C# avec Unity 6.

## Démarrer

Ouvrez `index.html` dans un navigateur moderne. Aucun serveur, compte ni installation n'est nécessaire.

## Fonctions

- Scène visuelle avec cube mobile.
- Éditeur de script C# simplifié.
- Contrôles Play, Pause et Stop.
- Inspector avec position, santé et vitesse.
- Console pour Debug.Log, avertissements et erreurs reconnues.
- Questions de connaissance et score.

## Limites

Ce laboratoire **ne compile pas C# et ne lance pas Unity**. Il analyse un sous-ensemble pédagogique de scripts avec `TrainingCube`, `Start`, `Update`, `Vector3.right/left/up/down`, `speed` et `Time.deltaTime`. Les erreurs sont des diagnostics pédagogiques et ne remplacent pas le compilateur Unity.

## Publication

Pour publier ce sous-dossier comme site GitHub Pages, utiliser GitHub Actions ou déplacer/copier le dossier dans une branche/dossier de publication. Un fichier `index.html` dans un sous-dossier ne rend pas automatiquement le site public sur GitHub Pages.
